# ЛР1. Облік спожитих калорій

## Опис сутності

Сутність предметної області — **Продукт** (порція їжі, яку спожив користувач).
Характеристики:

| Поле | Тип | Опис |
| --- | --- | --- |
| productName | String | Назва продукту |
| weightGrams | int | Вага спожитої порції, г |
| caloriesPer100g | double | Калорійність продукту на 100 г |
| proteinPer100g | double | Вміст білка на 100 г |
| mealType | String | Прийом їжі (сніданок/обід/вечеря/перекус) |

## Обчислювальна операція

Програма розраховує загальну кількість калорій та білка, отриманих зі
з'їденої порції:

```
totalCalories = caloriesPer100g * weightGrams / 100
totalProtein  = proteinPer100g  * weightGrams / 100
```

За допомогою `if / else if / else` програма також класифікує калорійність
прийому їжі (легкий / помірний / калорійний).

## Як запустити

```bash
javac Main.java
java Main
```

Після запуску програма послідовно запитує назву продукту, вагу порції,
калорійність та білок на 100 г, прийом їжі — і виводить форматований
результат (мінімум 2 знаки після коми для дробових значень).
