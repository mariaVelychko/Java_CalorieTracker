# ЛР2. Опрацювання масивів із застосуванням циклів

## Опис сутності

Клас **Product** (продовження ЛР1), предметна область — облік спожитих калорій.

| Поле | Тип | Опис |
| --- | --- | --- |
| name | String | Назва продукту |
| weightGrams | int | Вага спожитої порції, г |
| caloriesPer100g | double | Калорійність на 100 г |
| proteinPer100g | double | Вміст білка на 100 г |

Реалізовано конструктор, `toString()` та власний `equals()` (порівняння за всіма полями).

## Що реалізовано

**Рівень 1 (базовий)**
- Клас `Product` з 4 полями різних типів і конструктором
- Перевизначений `toString()`
- Заповнення масиву об'єктів у циклі `for` через `Scanner`
- Виведення масиву через `for-each`
- Підрахунок кількості продуктів, калорійніших за задану межу

**Рівень 2 (середній)**
- Сортування масиву методом простого обміну (**bubble sort**) за калорійністю на 100 г — без `Arrays.sort()`
- Виведення масиву до і після сортування

**Рівень 3 (високий)**
- Лінійний пошук об'єкта в масиві **за повним збігом** (через власний `equals()`, а не за окремим полем)

## Як запустити

```bash
javac Main.java Product.java
java Main
```

Програма послідовно запитує кількість продуктів, дані кожного продукту, межу калорійності для підрахунку, а потім — дані продукту для пошуку в масиві.
